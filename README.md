## 프로젝트 범위

∙ 실시간 채팅: 채팅을 통해 더욱 생생하게 소통합니다.<br>
∙ 스터디룸: 카테고리 별로 스터디룸을 검색하고 생성할 수 있습니다.<br>
∙ 캘린더: 개인 및 스터디별 일정을 관리할 수 있습니다.<br>
∙ 개인 프로필 관리: 마이페이지에서 프로필 설정, 스터디룸 기록 조회, 닉네임 설정 등 다양한 기능을 제공합니다.<br>
∙ 철저한 인증: 이메일 인증 방식으로 안전하게 회원가입할 수 있습니다.<br>
∙ 자유게시판: 다양한 주제로 소통할 수 있는 자유게시판을 통해 정보를 공유하고, 질문과 답변을 나눌 수 있습니다.<br>
∙ 게시판, 게시글 스크랩: 유용한 정보를 스크랩하여 언제든지 쉽게 접근할 수 있습니다.<br>
∙ 관리자 도구: 관리자 기능을 통해 회원, 채팅방, 게시판을 효율적으로 관리하고 모니터링합니다.<br>

## 팀원 소개

- 이하영<br>
  ∙ 원격 서버 설정 및 관리<br>
  ∙ 게시판 기능 API 구현 - 게시글, 댓글, 스크랩, 좋아요 기능

- 강서연<br>
  ∙ JWT 토큰 생성 및 검증으로 회원 기능 구현<br>
  ∙ 마이페이지 기능 API 구현 - 회원 정보 조회, 수정, 삭제(탈퇴)
- 김민상<br>
  ∙ 관리자 기능 API 구현 - 회원, 스터디룸, 채팅방, 게시글, 관리 기능<br>
- 윤수민<br>
  ∙ 캘린더 기능 API 구현 - 공공데이터를 활용한 캘린더 기능 구현

- 이형룡<br>

- 황예준<br>
  ∙ 채팅 기능 API 구현 - 이전 메세지 조회, 채팅방 생성, 조회, 삭제 기능<br>

- 이지원<br>
  ∙ Flowchar, UI wireframe 제작<br>
  ∙ 어드민, 스터디룸 목록, 채팅 화면 구현<br>

- 정영준<br>

  ∙ 게시판, 캘린더 화면 구현<br>
